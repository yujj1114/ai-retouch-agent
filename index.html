模型配置

填入 API Key 即启用真实模型（规划 + 文生图）；未配置时自动使用内置引擎（规则规划 + 程序生成，零费用）。

Key 仅保存在本机浏览器 localStorage，请勿在公共电脑使用。调用若被 CORS 拦截，请勾选下方「通过本地代理转发」。

启动方式：项目根目录执行 node server/proxy.js。勾选后由代理使用服务端 Key，上方 Key 字段不生效。
